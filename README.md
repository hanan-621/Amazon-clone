# Amazon Clone E-Commerce Website

## About the Project
This is a full-stack e-commerce learning project. It was built to practice MERN Stack Web Development.

## Technologies Used
- MongoDB
- Express.js
- React.js
- Node.js
- JavaScript

## Features
- User Registration and Login
- Product Listing
- Shopping Cart
- Order Management
- Admin Dashboard
- Checkout
- Chapa Test Payment Integration


## Usage


# Install dependencies
npm install
yarn install

# Run in development
npm run dev
yarn run dev

# Run in production
npm start
yarn start

## Project Purpose
This project was developed for learning and practicing full-stack web development.
